# Security Policy

## Supported Project Scope

This repository contains public documentation, setup files, and an evaluation
notebook for a sentiment classification model. It does not contain private
client data, private review data, credentials, or production infrastructure.

## Reporting a Concern

Please open a GitHub issue if you find:

- A dependency or setup instruction that creates avoidable security risk
- Accidental exposure of private data or credentials
- Unsafe inference guidance that could encourage misuse of customer feedback
- A reproducibility issue that could mislead downstream users

Do not include secrets, private data, or sensitive customer text in the issue.
Use a minimal synthetic example when possible.

## Maintainer Response

I will prioritize reports that affect privacy, reproducibility, dependency
safety, or the responsible use of the model.
